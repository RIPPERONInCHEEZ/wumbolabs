Quant Lab is a Markdown-first local LLM evaluation system.

It was built to replace ad hoc model testing with a more structured process for evaluating local language models across practical technical scenarios.

## Evaluation Areas

- honesty under uncertainty
- Linux troubleshooting
- Docker and networking issues
- ZFS safety
- coding usefulness
- configuration review
- long-context behavior
- niche factual honesty

Quant Lab emphasizes repeatable testing, practical prompts, captured raw outputs, and evidence-based conclusions.
