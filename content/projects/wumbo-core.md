Wumbo Core is my self-hosted homelab environment.

It centers on an Ubuntu server running Docker-based services for media, networking, dashboards, documentation, DNS, VPN-routed workloads, and storage management.

## Core Components

- Docker Compose service stack
- Plex and supporting media services
- qBittorrent behind Gluetun VPN
- AdGuard Home DNS
- Homepage dashboard
- Tautulli
- ZFS storage
- MkDocs documentation
- emergency rebuild procedures

## Operating Goal

The goal is to build infrastructure that can be operated, understood, recovered, and improved over time.
