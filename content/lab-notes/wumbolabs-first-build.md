WumboLabs is starting as a simple static site for documenting local AI, Linux, homelab, and self-hosting work.

The first version is intentionally conservative:

- Zola static site generator
- Markdown content
- plain CSS
- no npm dependency chain
- no CMS
- no database
- no unnecessary JavaScript

The goal is to build a site that is easy to maintain, easy to deploy, and simple enough to keep writing for.

This first version is not meant to be perfect. It is meant to exist.
