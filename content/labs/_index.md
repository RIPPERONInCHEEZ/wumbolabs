Each WumboLabs-tested model has exactly one canonical Labs page answering one question: **what do we currently know about this model?** Current state comes first; tested profiles, per-event evidence, and the complete testing history follow, with every value attributed to the profile and event that measured it.

The exact scientific reports live in the canonical public evidence repositories linked from each page. The [Lab Records](/records/) index remains the chronological stream of individual evidence events.
